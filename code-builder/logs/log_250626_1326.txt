## One-line Description

Checks if a given string is equal to its reverse.

## Edge Cases

*   Empty string: `""` should return `True`
*   Single character string: `"a"` should return `True`
*   String with non-alphanumeric characters: `"hello123!"` should raise an error
*   String with leading or trailing whitespace: `"  hello world  "` should return `False`

## Concrete Input->Output Examples

*   `is_palindrome("madam")`: `True`
*   `is_palindrome("hello")`: `False`
```

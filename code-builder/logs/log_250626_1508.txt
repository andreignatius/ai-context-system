Here's a simple Python function that checks if an input string is a palindrome:

```python
def is_palindrome(s: str) -> bool:
    """
    Returns True if the input string is a palindrome, False otherwise.
    
    :param s: The input string to check.
    :return: A boolean indicating whether the string is a palindrome.
    """
    s = ''.join(c for c in s if c.isalnum()).lower()  # Remove non-alphanumeric characters and convert to lowercase
    return s == s[::-1]  # Compare the string with its reverse
```

Here's an explanation of how this function works:

* We first remove any non-alphanumeric characters from the input string using a generator expression. This ensures that punctuation, spaces, etc., don't affect our palindrome check.
* We then convert the resulting string to lowercase to make the comparison case-insensitive.
* Finally, we compare the modified string with its reverse (`s[::-1]`). If they're equal, the original string is a palindrome.

You can test this function with different input strings, like so:

```python
print(is_palindrome("radar"))  # True
print(is_palindrome("hello"))  # False
print(is_palindrome("A man, a plan, a canal: Panama"))  # True (case-insensitive)
```

```python
def is_palindrome(s: str) -> bool:
    """
    Returns True if the input string is a palindrome, False otherwise.
    
    :param s: The input string to check.
    :return: A boolean indicating whether the string is a palindrome.
    """
    s = ''.join(c for c in s if c.isalnum()).lower()  # Remove non-alphanumeric characters and convert to lowercase
    return s == s[::-1]  # Compare the string with its reverse
```

Here's an explanation of how this function works:

* We first remove any non-alphanumeric characters from the input string using a generator expression. This ensures that punctuation, spaces, etc., don't affect our palindrome check.
* We then convert the resulting string to lowercase to make the comparison case-insensitive.
* Finally, we compare the modified string with its reverse (`s[::-1]`). If they're equal, the original string is a palindrome.
